## ✨ Features

### 🎥 Macro Recording & Playback
- Record your player’s **movement, rotation, hotbar slot, and key presses** (WASD, jump, sprint, sneak, attack, use).  
- Save and load macros to/from files for easy reuse.  

### 🛡️ Failsafe System
- Configurable **failsafe distance** and **backtrack** to prevent desync or unwanted macro actions.  
- Toggle failsafe strictness or ignore it entirely from the in-game UI.  

### 🎲 Randomization (RDM)
- Enable **random smoothing** between macro loops for more human-like movement.  

### 🖥️ In-Game GUI
- Manage macros with a clean UI: **save, load, delete, scroll, rename**.  
- Toggle randomization and failsafe settings directly from the UI.  
- Adjust failsafe backtrack value with intuitive buttons.  

### 📺 Overlay HUD
- Always-visible overlay shows **macro status** (`Idle`, `Recording`, `Playing`) and **duration**.  
- **Drag-and-drop positioning**: move the overlay anywhere with a simple drag-and-click workflow.  

### ⚡ Quality of Life
- Configurable hotkeys (**default: B = record, P = play**).  
- Macro actions auto-pause when a GUI is open (except ESC menu).  
- No chat spam: all macro status is shown in the **overlay**, not chat.  

---

## 🛠️ How to Use
- `/mrec` — Open the macro UI in-game.  
- **Record** — Press the record key to start/stop recording.  
- **Play** — Press the play key to start/stop playback.  
- **Overlay** — Use the UI’s *“Move Overlay”* button to reposition the HUD.  
- **Failsafe & RDM** — Toggle and adjust settings in the UI for your needs.  

---

## 💾 Installation
1. Download the latest release JAR.  
2. Place the JAR into your `mods` folder.  
3. Launch **Minecraft Fabric 1.26.2** and enjoy!
